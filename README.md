## 购买流程与几条避坑提醒

流程没什么花头：注册 → 选套餐 → 结算页填优惠码 → 支付宝/微信付款 → 后台开机。支持支付宝、微信等国内支付方式，不用折腾外币卡。

但有几条官网写明的规则，下单前最好心里有数：

1. **退款政策**：正价商品总流量不超过 10G 可全额退款；但用了优惠码、流量超 10G、或 IP 被墙的情况，都不退款。所以优惠码和"无理由退款"是互斥的，自己权衡。
2. **带宽是共享的**：默认共享带宽，官方只保证 99% 时间段达到标称带宽。国际带宽受出口和高峰影响，"100% 时间段跑满 1Gbps"这种承诺任何商家都给不了，DV 至少把话说明白了。
3. **禁止长期占用带宽**：精品线路系列（GIA/Pro/9929/CMIN2）都明写"禁止长期占用带宽"，拿它当下载机、天天拉满流量跑，被限速或停机别意外。
4. **业务限制**：官网明确禁止色情、欺诈、赌博、暴力、黑客、病毒、**跨境访问节点**等违反服务器所在地及使用者所在地法律的内容，发现即停机不退款并追责。这条是官网 FAQ 原文，买之前看清楚，别拿它干不该干的事。
5. **过户规则**：产品可以过户，费用 10 元，但剩余可用时间必须超过周期一半（月付 >15 天，年付 >183 天）。
